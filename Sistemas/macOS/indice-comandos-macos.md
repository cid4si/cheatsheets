## Introdução

Referência rápida e completa dos comandos disponíveis no Terminal do macOS. Os comandos estão organizados por categoria e em ordem alfabética para facilitar a consulta.

## Dicas de Utilização

- Use `man [comando]` para obter ajuda detalhada sobre qualquer comando
- Pressione Tab para completar automaticamente nomes de arquivos e comandos
- Use as setas para cima/baixo para navegar pelo histórico de comandos
- Utilize `Ctrl+R` para buscar comandos no histórico
- Combine comandos com operadores como `|` (pipe), `&&`, `||` e redirecionamentos `>`, `>>`, `<`
- Adicione `sudo` antes de um comando para executá-lo com privilégios de administrador
