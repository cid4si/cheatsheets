## Introdução

Referência rápida e completa de comandos disponíveis no Prompt de Comando (CMD) do Windows. Os comandos estão organizados em ordem alfabética para facilitar a consulta.

---

## Comandos em Ordem Alfabética

### A

- **ASSOC** - Exibe ou modifica associações de extensões de arquivo
- **ATTRIB** - Exibe ou altera atributos de arquivos

### B

- **BOOTCFG** - Configura propriedades do menu de inicialização
- **BREAK** - Define ou limpa verificação estendida de CTRL+C

### C

- **CACLS** - Exibe ou modifica listas de controle de acesso (ACLs) de arquivos
- **CALL** - Chama um programa batch a partir de outro
- **CD / CHDIR** - Exibe o nome do diretório atual ou muda para outro diretório
- **CHCP** - Exibe ou define o número da página de código ativa
- **CHKDSK** - Verifica um disco e exibe um relatório de status
- **CHKNTFS** - Exibe ou modifica a verificação de disco na inicialização
- **CLS** - Limpa a tela
- **CMD** - Inicia uma nova instância do interpretador de comandos do Windows
- **COLOR** - Altera as cores do primeiro plano e do plano de fundo do console
- **COMP** - Compara o conteúdo de dois arquivos ou conjuntos de arquivos
- **COMPACT** - Exibe ou altera a compactação de arquivos em partições NTFS
- **CONVERT** - Converte volumes FAT para NTFS
- **COPY** - Copia um ou mais arquivos para outro local

### D

- **DATE** - Exibe ou ajusta a data
- **DCOMCNFG** - Ferramenta de Serviços de Componente
- **DEFRAG** - Desfragmenta arquivos em um volume
- **DEL / ERASE** - Exclui um ou mais arquivos
- **DIR** - Exibe uma lista de arquivos e subdiretórios em um diretório
- **DISKCOMP** - Compara o conteúdo de dois disquetes
- **DISKCOPY** - Copia o conteúdo de um disquete para outro
- **DISKPART** - Exibe ou configura propriedades de partição de disco
- **DOSKEY** - Edita linhas de comando, recupera comandos e cria macros
- **DRIVERQUERY** - Exibe status e propriedades do driver de dispositivo atual

### E

- **ECHO** - Exibe mensagens ou ativa/desativa o eco de comandos
- **ENDLOCAL** - Encerra a localização de alterações de ambiente em um arquivo em lotes
- **EXIT** - Sai do programa CMD.EXE (interpretador de comandos)
- **EXPAND** - Descompacta um ou mais arquivos compactados

### F

- **FC** - Compara dois arquivos ou conjuntos de arquivos e exibe as diferenças
- **FIND** - Procura uma string de texto em um arquivo ou arquivos
- **FINDSTR** - Procura strings em arquivos (com suporte a expressões regulares)
- **FOR** - Executa um comando para cada item em um conjunto
- **FORMAT** - Formata um disco para uso com Windows
- **FSUTIL** - Exibe ou configura as propriedades do sistema de arquivos

### G

- **GOTO** - Direciona o interpretador de comandos para uma linha rotulada em um programa batch

### H

- **HELP** - Fornece informações de ajuda para comandos do Windows
- **HOSTNAME** - Exibe o nome do host atual

### I

- **ICACLS** - Exibe, modifica, faz backup ou restaura ACLs para arquivos e diretórios
- **IF** - Realiza processamento condicional em programas em lote
- **IPCONFIG** - Exibe informações de configuração de IP

### L

- **LABEL** - Cria, altera ou exclui o rótulo de volume de um disco
- **LODCTR** - Atualiza valores de registro de contadores de desempenho

### M

- **MD / MKDIR** - Cria um diretório
- **MODE** - Configura um dispositivo do sistema
- **MORE** - Exibe saída, uma tela por vez
- **MOVE** - Move um ou mais arquivos de um diretório para outro

### N

- **NET** - Gerencia recursos de rede
- **NETSH** - Ferramenta de configuração de rede
- **NETSTAT** - Exibe estatísticas de protocolo e conexões de rede atuais
- **NSLOOKUP** - Exibe informações para diagnosticar infraestrutura DNS

### P

- **PATH** - Exibe ou define o caminho de pesquisa para arquivos executáveis
- **PATHPING** - Rastreamento de rota que também fornece informações de latência
- **PAUSE** - Suspende o processamento de um arquivo em lotes
- **PING** - Testa uma conexão de rede
- **POWERCFG** - Gerencia configurações de energia
- **PRINT** - Imprime um arquivo de texto
- **PROMPT** - Altera o prompt de comando do Windows

### R

- **RECOVER** - Recupera informações legíveis de um disco danificado ou defeituoso
- **REG** - Ferramenta de registro de linha de comando
- **REM** - Grava comentários em arquivos batch ou CONFIG.SYS
- **REN / RENAME** - Renomeia um arquivo ou arquivos
- **REPLACE** - Substitui arquivos
- **RD / RMDIR** - Remove um diretório
- **ROBOCOPY** - Ferramenta avançada para cópia de arquivos e árvores de diretório
- **ROUTE** - Manipula tabelas de roteamento de rede

### S

- **SC** - Exibe ou configura serviços (gerenciador de controle de serviços)
- **SCHTASKS** - Agenda comandos e programas para serem executados
- **SET** - Exibe, define ou remove variáveis de ambiente
- **SETLOCAL** - Inicia a localização de alterações de ambiente em um arquivo em lotes
- **SHUTDOWN** - Permite desligamento local ou remoto do computador
- **SORT** - Classifica a entrada
- **START** - Inicia uma janela separada para executar um programa ou comando
- **SUBST** - Associa um caminho a uma letra de unidade
- **SYSTEMINFO** - Exibe informações específicas da configuração da máquina e do sistema operacional

### T

- **TASKLIST** - Exibe todas as tarefas em execução, incluindo serviços
- **TASKKILL** - Encerra ou interrompe um processo ou aplicativo em execução
- **TIME** - Exibe ou ajusta a hora do sistema
- **TIMEOUT** - Aguarda o número especificado de segundos
- **TITLE** - Define o título da janela para uma sessão CMD.EXE
- **TRACERT** - Determina o caminho para um destino

### T

- **TREE** - Exibe graficamente a estrutura de diretório de uma unidade ou caminho
- **TYPE** - Exibe o conteúdo de um arquivo de texto

### V

- **VER** - Exibe a versão do Windows
- **VERIFY** - Informa ao Windows se deve verificar se os arquivos estão gravados corretamente
- **VOL** - Exibe o rótulo e o número de série do volume de um disco

### W

- **WHERE** - Localiza e exibe arquivos em um diretório que correspondem a um padrão
- **WHOAMI** - Exibe informações sobre o usuário atual
- **WMIC** - Exibe informações WMI em um formato de linha de comando interativo

### X

- **XCOPY** - Copia arquivos e árvores de diretórios

---

## Dicas de Utilização

- Use `comando /?` para obter ajuda sobre qualquer comando
- Execute `cmd` como administrador para operações que exigem elevação de privilégios
- Use a tecla Tab para completar automaticamente nomes de arquivos e diretórios
- Utilize as setas para cima/baixo para navegar pelo histórico de comandos
- Combine comandos com operadores como `&`, `&&`, `||` e redirecionamentos `>`, `>>`, `<`
